# Experiment 02 spec

Read `../README.md` (the theory) and `../EXPERIMENT-01.md` (what the first round found) before anything else.

Experiment 01 showed that residual-heat recruitment and heat spreading work as local rules, but both automata ended up as smart counting: nothing was shared across contexts, nothing ever melted, held states were never used, and local heat couldn't tell resolvable misfit from noise. It also used weak and inconsistent baselines. Experiment 02 fixes the measurement first, then tests the parts of the theory that round one never reached.

## Fixed constraints

- **Rust, stable, no external crates** (standard library only). Release builds. No viewer.
- **No backpropagation, gradients, loss functions, fitness functions or optimisers.** No global error signal.
- **Local rules only.**
- **Online, single pass.** One character at a time, learning as it goes. Internal settling during a quiet period with no input is allowed.
- **Sparse.** Only a small fraction of the automaton is active at any step.
- **Deterministic.** A seeded PRNG you write. Same seed, same result.
- **Honest measurement.** The harness and baselines are the judge. Models never modify them. Failure is a valid result.
- **No bolted-on counter.** A model's prediction must come from its own states, transitions and assemblies. If any part of a model's probability calculation is mathematically equivalent to a counting model, say so explicitly in its findings (round one's m001 borrowed Witten–Bell smoothing; say it if you do).

Each model is its own crate implementing the trait. The `run` binary is told which models to run (by feature flag or by a simple registry in `run.rs` that model agents add one line to). `cargo run --release -p harness --bin run` must run everything in a few minutes at most.

## The Automaton trait

```rust
pub trait Automaton {
    fn name(&self) -> &str;
    /// Probability distribution over the alphabet for the next character.
    /// Must sum to 1 and give every symbol nonzero probability.
    fn predict(&mut self) -> Vec<f64>;
    /// The character arrives. Advance state; learn if learning is on.
    fn observe(&mut self, ch: u8);
    fn set_learning(&mut self, on: bool);
    /// A quiet period of `steps` with no input.
    fn quiet(&mut self, steps: usize);
    /// Current internal energy (misfit), for the confusion test.
    fn energy(&self) -> f64;
    /// Free-form key/value stats for the report (cells used, frozen, etc.).
    fn stats(&self) -> Vec<(String, f64)>;
}
```

Models are constructed by `fn new(seed: u64, capacity: usize) -> Self`. `capacity` is a hard limit on the model's main units (cells, states, whatever it uses), so that tests can force scarcity.

## The shared corpus

Generated by the harness, deterministically from the seed. Alphabet: lowercase letters, space, full stop, newline (keep it small). About 60,000 characters of training stream. It must support the tests below:

- **A grammar** of simple sentences: determiner, optional adjective, noun, verb, optional prepositional phrase. Roughly 40–80 words.
- **Held-out combinations.** Nouns and verbs fall into groups. A specific set of noun–verb pairs (for example a quarter of all pairs) never appears in the training stream, although every noun and every verb appears many times in other pairs.
- **Topics.** Two (or three) topics, each with its own extra vocabulary (e.g. a farm topic, a sea topic), arranged in long blocks of a few hundred characters, interleaved through the stream.
- **A few fixed longer sentences** that recur occasionally.

## Baselines

Counting models, also online and single pass, given every advantage:

- **PPM-C** (escape method C) with exclusion, orders 1 to 8.
- **Witten–Bell** interpolated, orders 1 to 8.

Report all, and highlight the best single baseline per test. Models are compared with the **best** baseline, not a weak one.

## Tests

For every model and baseline.

1. **Prediction.** Prequential bits per character over the training stream, full stream and final 20%.
2. **Composition (held-out combinations).** After the stream, with learning off, score sentences containing only the held-out noun–verb pairs. Report bpc on the verb characters specifically (the place where a counter has never seen this noun followed by this verb), and on whole sentences. This is the main test of round two.
3. **Persistence (topic return).** Score the first 100 characters after each return to a topic, versus the same characters later in the block. A model that holds topic state should drop less at the boundary than counting does.
4. **Noise recovery.** With learning off, corrupt held-out text at 5% and 10% (insert, drop, swap). Report bpc overall and bpc on the 10 characters following each corruption.
5. **Forgetting.** With capacity deliberately scarce: train on stream A, then on a different stream B (new vocabulary, same grammar shape), then score A again with learning off. Report how much of A's performance survives. Run each model with its freezing on and off. This is the test that gives freezing a job.
6. **Confusion.** Energy on familiar sentences, novel combinations of known words, unseen words, random letters.
7. **Thinking without data.** Train on half the stream, quiet period or none (same seed), then score the second half with learning on. Report the difference.
8. **Cost.** Wall time per model per test, peak units used.

Run tests 1–7 on three seeds; report mean and per seed. Tune nothing on seeds 2 and 3.

### Added in round three

Tests 1–8 are unchanged and give identical numbers for the same seed. Two tests are added, scored the same way (three seeds, compared with the best baseline):

9. **Unseen noise shapes.** Test 4 gave away the shape of corruption (insert, drop, adjacent swap). Test 9 uses kinds no model was told about: a character doubled, two characters transposed at distance 2, a burst of 2–3 random characters, and a word boundary moved one place left or right. It reuses test 4's clean held-out text, corrupted at 5% and 10%, with learning off, after the main run's other evaluations. Report bpc overall, bpc on the 10 characters after each corruption, and the latter per kind. Headline: bpc overall at 10%.
10. **Context conflict.** A test of "nothing is wrong, only out of context" and the context rung. A separate deterministic stream in which each paragraph opens with one cue of a context pair (morning / evening, shop / farm, summer / winter, won / lost, boat / train) and later contains frames whose completion depends on it ("the sky was blue" / "red", "she bought bread" / "she fed the cows"). Neutral grammar sentences always separate cue and frame, so the cue is more than 8 characters back (the corpus check verifies this, and that the 8 characters before a completion leave the context near 1 bit uncertain). A fresh instance reads about 20,000 characters with learning on, then a 6,000-character held-out stream with learning off. Report bpc on the context-dependent completion characters (headline), on their first character, and on the whole held-out stream. The same run is repeated, same seed, with a 5,000-step quiet period at the paragraph boundary halfway through the learning stream; report the difference on the completion characters. This is where internal conflict should give thinking something to resolve.

## m000-reference

The harness agent writes a trivial model (for example, an order-2 table) so the harness can be run and checked before the real models exist. It is not part of the comparison.

## Findings

Each model writes `models/<name>/FINDINGS.md`: what it built, mapped to the README; results per test with the best baseline alongside; what worked and what didn't; which theory claims were supported, contradicted, or untested; surprises; next steps. The harness writes `results/RESULTS.md` with all numbers side by side.
